# Final report and code evidence

The final English report is submitted separately in AAAI format, six pages including references. Course submission documents containing member details are kept outside the public code repository. This directory retains bibliographic material; the public evidence needed to check the report is included in the repository.

The report follows the implemented progression from CutMix to content selection, seam-aware rectangles and constrained DP boundaries. It reports the paired boundary improvement, classification near the baseline, measured training cost and the same-host confirmation without inventing test scores or seed statistics.
