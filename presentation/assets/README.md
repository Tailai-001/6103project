# Presentation asset provenance

Numeric figures can be rebuilt with `python analysis/reproduce_results.py`; actual mixed-image examples additionally require CIFAR-100. The original CutMix illustration is in the unchanged upstream reference and must retain its Yun et al., ICCV 2019 citation.

The course presentation and narration are submitted separately. No video, dataset or model checkpoint is required for this code delivery.
