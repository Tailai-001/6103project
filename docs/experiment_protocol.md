## 建议的面积匹配方案

先按官方中心采样和裁剪规则得到实际矩形，再固定其高宽平移得到候选集。候选 0 保留原矩形，E1 直接选它；E2/E3 对同一个候选集评分。其余候选必须完整位于图像内。这个方案可保持 E1–E3 的实际面积分布，并使 K=1 能与 E1 对照。它是待评审的设计，并非已完成代码。

Source 与 Target 同坐标粘贴；源数据从未修改 batch 读取。若 K 个候选全同分，采用同一确定规则。若 γ=0，E3 必须使用 E2 的同一候选、得分归一化、随机输入和排序规则。

## 数据与运行记录

数据划分只做一次并共享。训练/验证可采用不同 transform，但索引必须指向同一份原始训练集，验证 transform 不应含随机 crop/flip。记录增强前后的输入范围，避免把标准化后的通道直接用于 Sobel。

每次运行至少记录 `run_id`、experiment、policy、seed、git SHA、完整配置、划分校验值、环境/设备、开始时间、状态、验证选择依据、日志与 checkpoint 链接。最终测试还要记录选定 checkpoint 的来源；不要根据测试结果继续选择参数。

K=1/4/8 为计划消融；γ 搜索和更多鲁棒性实验视资源决定。噪声、模糊、遮挡若是自建扰动，需记录生成规则，不与已有标准鲁棒性基准混称。

## 检查与结果汇总

算法检查至少包含：实际面积与像素替换一致、矩形越界、零/极小 patch、奇数尺寸、常量图像、K=1、γ=0、固定随机输入复现、batch size 1，以及支持设备和 dtype 上的有限输出。此清单由实现阶段补充为必要测试，当前尚未实现。

统一报告准确率使用百分比还是小数、Macro-F1 的类别范围和 `zero_division` 规则。多 seed 记录每次原值，并明确均值与标准差定义；单 seed 不伪造标准差。训练中的混合样本 accuracy 不能替代干净验证集评价。不得挑选最好 seed 充当平均结果。
